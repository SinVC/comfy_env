## 已修改的设计

- **install、node remove 和 tx promote** 把依赖组编辑和锁定放在生产备份之前。锁冲突可以直接退出或进入事务冲突处理。删除插件源码时只备份受影响的插件目录。
- **tx 和 update** 以当前生产包集作为观测基线，使候选同步引入的核心包变更也会进入审批。候选同步失败与 ComfyUI 已运行但返回非零分别处理。`update promote` 在晋升已锁定快照前比对暂存时的生产真相，避免覆盖中途执行的 pin。
- **env import** 将 Python、平台、校验和及 bundle 锁检查放在首次目标写入之前。恢复范围包含先前的配置、依赖真相、注册表和受影响的节点目录，并区分已有环境和首次导入。
- **架构、ADR 与使用入口** 将进程管理、跨调用日志和目录快照分别放到使用它们的切片。README 列出 Rust 已可用命令，旧 CLI 文档标注为 Bash 行为参考。
